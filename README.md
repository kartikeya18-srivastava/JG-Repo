# JG University Website Redesign

This repository contains a high-fidelity, premium redesign of the official **[JG University Website](https://jguni.in/)**, built using the modern frontend stack. The objective is to evolve the online academic presence from a generic AI-template style to a sleek, editorial-grade, and branded academic identity.

## 🚀 Live Redesign Features

- **Branded Design System:** Modern and editorial slate & blue color palette, structured using custom typography tokens.
- **Authentic Institutional Assets:** Zero generic stock/AI assets. Integrates original logos and actual campus/student photography scraped directly from their official servers.
- **Interactive Stats Counter:** Animated counting cards highlighting the university's academic and industrial footprint, triggered dynamically upon scrolling.
- **High-Fidelity Animations:** Smooth page-entry transitions, staggered text fade-ins, and soft continuous hover actions using **Framer Motion**.
- **Admissions Tickers & Floating Widgets:** Persistent announcement bars and quick-apply floating action buttons (FABs) built to maximize lead generation.
- **Fully Responsive & Clean Code:** Built from the ground up to be semantic, SEO-optimized, and ultra-fast.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router & React 19)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 💻 Getting Started

### 1. Clone the project
```bash
git clone https://github.com/kartikeya18-srivastava/JG-Repo.git
cd JG-Repo/jguni-redesign
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser to see the live project!
